# Supplementary Table Sx. Run1 missed-study metadata and potential retrieval-bias analysis

For each Run1 query, gold PMID retrieval was determined using an exact intersection query: `(Run1 PubMed Boolean query) AND (gold PMID OR block)`. PubMed metadata were used for descriptive classification of missed-study patterns. Because PubMed indexing can change over time, these results should be interpreted alongside the official Run1 cut0/cut70 metrics.
